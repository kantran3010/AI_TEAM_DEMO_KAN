# 🤖 AI MULTI-AGENT WORKSPACE (GIAO DIỆN WEB APP TRỰC QUAN)

Hệ thống Đa Tác Tử (Multi-Agent System) tích hợp sẵn ứng dụng giao diện trực quan (Web App) — **không cần gõ lệnh trong PowerShell nữa**. Chỉ cần mở app, chọn Team và nhập ý tưởng!

---

## 🚀 CÁCH KHỞI ĐỘNG ỨNG DỤNG (1 CLICK CHUỘT)

1. Mở thư mục `D:\AI TEAM` trong máy tính của bạn.
2. **Nhấp đúp chuột vào file `Chay_App.bat`**.
3. Ứng dụng sẽ tự động mở giao diện điều khiển ngay trên trình duyệt web của bạn!

*(Hoặc nếu muốn chạy bằng lệnh: `uv run streamlit run app.py`)*

---

## 🌟 2 TÙY CHỌN CHÍNH TRÊN GIAO DIỆN

### 🛍️ Option 1: Team Bot AI Affiliate Marketing (Video + Bài Viết + Ảnh AI)
- **Đầu vào:** Nhập tên sản phẩm, link Shopee/TikTok Shop hoặc đặc điểm nổi bật.
- **Hệ thống 5 Bot tự động chạy song song:**
  1. 🕵️ **Bot 1:** Nghiên cứu insight khách hàng & tìm 5 góc tiếp cận triệu view.
  2. 🎬 **Bot 2:** Viết 3 kịch bản video ngắn TikTok/Reels phân cảnh chi tiết từng giây.
  3. ✍️ **Bot 3:** Viết chuỗi bài Threads viral, review Facebook Group & Blog SEO.
  4. 🎨 **Bot 4:** Thiết kế 5 concept hình ảnh giới thiệu (Hero Studio, Lifestyle, Macro, Banner) & xuất câu Prompt AI chuẩn cho Midjourney v6, Flux.1, DALL-E 3.
  5. 🛡️ **Bot 5:** Rà soát từ cấm sàn TikTok/Facebook & tạo bộ CTA giục mua (FOMO).
- **Tính năng trên App:** Xem từng tab riêng, copy prompt ảnh chỉ 1 click, bấm nút tải trọn bộ tài liệu `.md`.

---

### 💻 Option 2: Team AI Lập Trình Phần Mềm (Dev Team)
- **Đầu vào:** Nhập yêu cầu/tính năng phần mềm bạn muốn tạo.
- **Quy trình tự động hóa khép kín:**
  1. 📝 **Agent 1:** Viết kịch bản đặc tả kỹ thuật (SRS).
  2. 💻 **Agent 2:** Lập trình toàn bộ mã nguồn Python.
  3. 🧪 **Agent 3:** Viết test cases, chạy Pytest thực tế & tự vá lỗi (Self-Healing) cho đến khi 100% Pass.
- **Tính năng trên App:** Xem trực tiếp từng file code có highlight màu sắc, xem log chạy test, tải toàn bộ source code về dưới dạng file `.zip`.

## 🔑 Cài Đặt API Key Ngay Trên Giao Diện

Bạn không cần mở file `.env` chỉnh sửa thủ công nữa:
- Trên thanh bên trái (Sidebar) của App, có sẵn ô nhập **Google Gemini API Key** (hoặc OpenAI / Groq).
- Chỉ cần dán key vào là hệ thống tự động lưu và sử dụng ngay!
